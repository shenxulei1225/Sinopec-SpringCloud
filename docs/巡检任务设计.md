## 1. 总体定位

### 1.1 巡检任务编排模块 cheers-inspection-task 定位

**负责**:

- 任务创建、编辑、取消、冻结、中止、恢复、换设备
- 主任务/子任务生成
- 草稿、模板
- 任务候选、任务评估、冲突检测
- 任务列表、详情、看板、日志读模型
- 与 device / twin / scene / facility / inspection-model 协同

 inspection-task 核心
    - 主任务
    - 子任务
    - 任务创建
    - 任务编辑
    - 任务详情
    - 任务列表
    - 任务看板基础操作
    - 草稿
    - 模板
    - 冲突检测
    - 任务候选
    - 路线评估

**它不负责成为以下领域的主数据源**:

- 设备主数据
- 场景平台主数据
- twin 映射主数据
- 站场主数据

### 3.3 跨模块协同层

    cn.cheers.x.inspection.integration
    ├── device
    ├── facility
    ├── twin
    ├── scene
    └── user

这里建议放：
    - facade/client 调用封装
    - 外部响应转换
    - 错误翻译
    - 防止 task service 里到处散落跨模块调用

**device 模块持有**
    - 设备主数据
    - 设备状态
    - 设备能力
    - 设备外设/传感器
    - 基站/在线状态
    - 业务状态
    inspection-task 调用 device 暴露的能力
        - 查询设备详情
        - 查询设备状态
        - 查询设备可执行性
        - 查询设备外设状态
        - 查询设备能力类型
        - 查询设备列表 (按 site/type)
    inspection-task 不做的事
        - 不维护设备主档
        - 不维护传感器主档
        - 不维护基站主档
**twin 模块持有**
    - twin mapping
    - 业务对象与三维实例映射
    - 场景对象绑定关系
    inspection-task / inspection-model 调用 twin 的能力
        - 按 businessKey / objectId / pointId 查询场景实例映射
        - 查询三维实例定位信息
        - 查询点位落图关系
    twin 不做的事
        - 不持有任务业务状态
        - 不持有任务模板
        - 不持有任务执行逻辑
**scene-platform 模块持有**
    - scene/group/actor/instance
    - 场景树
    - 场景运行时结构
    inspection-model/inspection-task 调用 scene 的能力
        - 获取场景树
        - 获取 group / actor / instance
        - 查询 scene runtime package
        - 查询挂载节点信息
    scene-platform 不做的事
        - 不决定任务创建逻辑
        - 不决定任务状态流转
        - 不存任务业务表
**facility-management 持有**
    - site
    - facility
    - 区域/层级

### 3.5 service 拆分

按照规范，显式拆成三类:

1. 命令侧 service:
    task 任务
    - InspectionTaskService
    - createTask 创建任务
    - updateBaseTask 修改主任务
    - updateSubTask 修改子任
    - cancelTask 删除/取消任务
    - cancelBaseTask 删除/取消子任务
    - freezeTask 冻结任务
    - unfreezeTask 解冻任务
    - suspendTask 中止任务
    - forceSuspendTask 强制中止任务
    - replaceTaskDevice 换设备
    - determineStart 确定启动
draft 任务草稿
    - InspectionTaskDraftService 任务草稿
    - createDraft 创建草稿  
    - updateDraft 更新草稿
    - deleteDraft 删除草稿
template 任务模板
    - InspectionTaskTemplateService
    - createTemplate 创建模板
    - updateTemplate 更新模板
    - deleteTemplate 删除模板
    - importTemplate 导入模板
    - enableTemplate 启用模板
    - disableTemplate 禁用模板
inspection model
    - InspectionObjectService 巡检对象
    - ExecutionPointService 巡检点位
    - InspectionItemService 巡检检查项
    - InspectionSpecService 巡检规范

2. 查询侧 service
task query
    - InspectionTaskQueryService
    - pageBaseTask 主任务分页
    - getBaseTaskDetail 主任务概况
    - getSubTaskDetail 子任务概况
    - pageTaskLog 任务日志分页
    - pageCancelTask 
    - pageBoardTask 
    - getTaskOverview 获取任务总览
candidate/query support
    - InspectionTaskCandidateQueryService 巡检可用对象查询
    - InspectionTaskRouteQueryService 巡检路线查询
inspection model query
    - InspectionObjectQueryService 任务对象查询
    - ExecutionPointQueryService 巡检点位查询
    - InspectionSpecQueryService 巡检规范查询
任务详情
    - InspectionTaskDetailView
任务列表
    - InspectionTaskPageItemView
看板
    - InspectionTaskBoardItemView
模板详情
    - InspectionTaskTemplateDetailView
点位详情
    - ExecutionPointDetailView

3. 访问控制 service
    - InspectionTaskAccessService
    - InspectionModelAccessService
职责：
    - 站场访问
    - 对象可见性
    - 点位可见性
    - 模板操作权限
    - 任务操作权限

五、校验分层建议
你给的规范要落地，我这里直接按任务域拆。

1. 前端本地校验
任务创建/编辑表单
    - 任务名称必填
    - 名称长度限制
    - 执行类型必填
    - 设备类型必填
    - 设备必选
    - 日期必填
    - 时间列表必填
    - 周/月规则格式
    - 预设任务必须选模板
    - 灵活任务必须先完成路线评估
    - JSON 格式合法
    - 条件必填
模板表单
    - 模板名称必填
    - 长度限制
    - 关联对象必选
    - 路线配置格式合法

2. controller 异步校验接口
task
    - 任务名称唯一性
    - 路线预估
    - 可执行性校验
    - 冲突预检查
    - 设备推荐
template
    - 模板名称唯一性
inspection model
    - 编码唯一性
    - 同级名称唯一性（如果前端交互确实需要）

3. service 提交兜底
task
    - 任务名唯一性
    - 时间合法性
    - 设备最终可用性
    - 设备外设状态
    - 在线状态
    - 基站状态
    - 路线有效性
    - 冲突任务校验
    - 主子任务一致性
    - 状态流转合法性
    - 权限校验
inspection model
    - object/point/item/spec 存在性
    - 删除前约束
    - 引用关系合法性
