1. 编排引擎需要的查询:
  . 查询某天/某时间窗口内需要执行的需求
    . 查询特定排期模式的需求
    . 查询特定重复模式的需求
    . 查询某站点关联的需求
    . 查询有效期内的需求
2. 生成候选时间点时：需要根据 requirement 生成时刻表
  . 按策略ID查询所有关联的需求
    . 按日期范围查询在有效期内的需求
3. 任务调度时：需要找到满足条件的需求
  . 按排期模式查询（固定时间点/间隔执行/自动编排）
    . 按重复维度查询（一次性/每日/每周/每月）
    . 按星期几查询（weekDays）
    . 按每月几号查询（monthDays）


| 分类       | 方法                                      | 编排场景                 |
| -------- | --------------------------------------- | -------------------- |
| **核心查询** | selectActiveRequirements                | 引擎启动时加载所有活跃需求        |
|          | selectByPolicyId                        | 按策略分组编排              |
|          | selectByScheduleMode                    | 按模式（固定时间点/间隔/自动编排）查询 |
|          | selectByRepeatMode                      | 按维度（一次性/每日/每周/每月）查询  |
| **日期范围** | selectEffectiveOnDate                   | 查询某天有效的需求（判断是否在期内）   |
|          | selectEffectiveBetween                  | 预生成一段时间的排期计划         |
| **组合查询** | selectByScheduleModeAndEffectiveBetween | 某模式的预编排              |
|          | selectByRepeatModeAndEffectiveBetween   | 每周/月模式的展开            |
| **批量操作** | selectByIds                             | 批量加载指定需求             |
| **模板管理** | selectTemplates                         | 加载可复用的模板             |
|          | selectByTemplateName                    | 模板去重校验               |
