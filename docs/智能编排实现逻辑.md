# 智能编排引擎实现逻辑

## 零、设计可行性分析

### 0.1 为什么要这样分层设计

#### 问题：为什么需要 Requirement + Policy 两层抽象？

**核心矛盾**：
- 用户关心的是"何时执行"（业务语义）
- 算法关心的是"如何调度"（执行参数）

| 层级 | 关注点 | 示例 |
|------|--------|------|
| **Requirement（需求层）** | 业务约束：什么时候要执行？ | 每天3次、每周一、每2小时 |
| **Policy（策略层）** | 执行约束：执行时有什么弹性？ | 允许提前30分钟、允许延后60分钟 |

**分离价值**：
```
场景1：国标巡检（严格）
  Requirement: 每2小时执行一次
  Policy: 不允许提前/延后

场景2：同一业务，临时调整为灵活模式
  Requirement: 每2小时执行一次（不变）
  Policy: 允许提前30分钟、延后60分钟（切换策略）
  → 用户只需切换 Policy，无需修改业务规则
```

**为什么不是单一模型？**
- 如果混合在一起，修改灵活性参数时容易误改业务规则
- 不同任务可能共享相同的"何时执行"但有不同的"执行弹性"
- Policy 可以做成预设模板（严格/灵活/智能），用户一键切换

#### 问题：为什么需要三种排期模式？

**固定时间点 vs 间隔执行 vs 自动编排**

| 模式 | 用户输入 | 算法复杂度 | 适用场景 |
|------|----------|------------|----------|
| **固定时间点** | 明确时刻 | ⭐ 最低 | 定点打卡、每日例会 |
| **间隔执行** | 固定周期 | ⭐⭐ 中等 | 国标巡检、流水线检测 |
| **自动编排** | 执行次数 | ⭐⭐⭐ 较高 | 智能避峰、灵活调度 |

**三种模式的设计合理性**：
1. **固定时间点**：满足精确控制需求，用户完全掌控执行时刻
2. **间隔执行**：满足周期性需求，算法只需按固定间隔展开
3. **自动编排**：满足智能调度需求，用户只关心次数，算法负责分配

**为什么不用一种模式覆盖所有场景？**
- 固定时间点 + 间隔 = 需要额外的"基准时间"参数，复杂度上升
- 自动编排 = 需要均匀分布算法，对精确控制场景不友好
- 三种模式各有边界，互不重叠，配置清晰

### 0.3 如何同时满足多个配置要求

#### 场景：同时满足以下约束
1. 国标要求：每2小时巡检一次
2. 每日约束：每天不超过6次
3. 时间窗口：只在08:00-20:00执行
4. 每周要求：每周至少1次
5. 冲突策略：允许顺延

```java
/**
 * 多约束综合校验流程
 *
 * 每个候选时间点需要依次通过以下校验：
 */
public boolean validateCandidate(CandidateTimePoint candidate) {
    Requirement req = candidate.getRequirement();

    // P0 - 硬约束
    if (!checkTimeWindow(candidate.getTime(), req)) return false;
    if (!checkRepeatMode(candidate.getDate(), req)) return false;

    // P1 - 业务约束（计数校验）
    if (!checkMinDailyCount(candidate.getDate(), req)) return false;
    if (!checkMinWeeklyCount(candidate.getDate(), req)) return false;
    if (!checkMinMonthlyCount(candidate.getDate(), req)) return false;

    // P2 - 限流约束（超过则标记跳过）
    if (exceedsMaxDailyCount(candidate.getDate(), req)) {
        candidate.markSkipped("超过每日最大次数");
        return false;
    }

    // P3 - 调度弹性（在范围内标记可调整）
    if (candidate.getTime().isBefore(req.getWindowStartTime())) {
        candidate.setAdjustable(true);
        candidate.setAdvanceMinutes(calculateAdvanceMinutes(candidate, req));
    }

    return true;
}
```

```java
/**
 * 检测配置矛盾
 */
public List<String> detectConfigurationConflicts(Requirement req) {
    List<String> conflicts = new ArrayList<>();

    // 检测：min > max
    if (req.getMinExecutionsPerDay() != null
        && req.getMaxExecutionsPerDay() != null
        && req.getMinExecutionsPerDay() > req.getMaxExecutionsPerDay()) {
        conflicts.add("每日执行次数约束矛盾：最少" + req.getMinExecutionsPerDay()
                + "次 > 最多" + req.getMaxExecutionsPerDay() + "次");
    }

    // 检测：间隔执行 vs 国标次数
    if (req.getScheduleMode() == 2 && req.getTaskCycleMinutes() != null) {
        int calculatedDaily = calculateDailyCount(req);
        if (req.getMinExecutionsPerDay() != null
                && calculatedDaily < req.getMinExecutionsPerDay()) {
            conflicts.add("间隔执行无法满足国标要求："
                    + "间隔" + req.getTaskCycleMinutes() + "分钟"
                    + "每天最多" + calculatedDaily + "次，"
                    + "但要求最少" + req.getMinExecutionsPerDay() + "次");
        }
    }

    return conflicts;
}
```

### 0.4 设计优势总结

| 设计点 | 优势 | 实际价值 |
|--------|------|----------|
| **Requirement + Policy 分离** | 业务规则与执行弹性解耦 | 切换Policy不影响业务逻辑 |
| **三种排期模式** | 各有语义边界清晰 | 用户按需选择，配置直观 |
| **硬约束 vs 软约束** | 优先级清晰 | 算法有明确处理方向 |
| **时间窗口约束** | 灵活的时间范围 | 支持夜间停机、午休避峰 |
| **执行次数约束** | 满足法规/限流 | 国标合规、负载控制 |
| **冲突处理策略** | 可预测的冲突结果 | skip/postpone/split 三种策略 |

## 三、核心实现流程

### 3.1 编排引擎主流程

```java
public class ScheduleEngine {

    public List<SchedulePlan> generatePlans(LocalDate startDate, LocalDate endDate) {
        // Step 1: 加载配置
        List<InspectionTask> tasks = taskMapper.selectActiveTasks();

        // Step 2: 按策略分组
        Map<Long, List<InspectionTask>> tasksByPolicy = tasks.stream()
                .collect(Collectors.groupingBy(InspectionTask::getSchedulePolicyId));

        // Step 3: 逐组生成候选时间点
        List<SchedulePlan> plans = new ArrayList<>();
        for (Map.Entry<Long, List<InspectionTask>> entry : tasksByPolicy.entrySet()) {
            Long policyId = entry.getKey();
            List<InspectionTask> groupTasks = entry.getValue();

            // 查询策略参数
            SchedulePolicy policy = policyMapper.selectById(policyId);

            // 查询该策略关联的需求
            List<Requirement> requirements = requirementMapper.selectByPolicyId(policyId);

            // 生成候选点
            List<CandidateTimePoint> candidates = generateCandidates(
                    requirements, startDate, endDate, policy);

            // 冲突检测与处理
            List<SchedulePlan> resolvedPlans = resolveConflicts(candidates, policy);

            plans.addAll(resolvedPlans);
        }

        return plans;
    }
}
```

### 3.2 候选时间点生成

```java
public List<CandidateTimePoint> generateCandidates(
        List<Requirement> requirements,
        LocalDate startDate,
        LocalDate endDate,
        SchedulePolicy policy) {

    List<CandidateTimePoint> candidates = new ArrayList<>();

    for (LocalDate date = startDate; !date.isAfter(endDate); date = date.plusDays(1)) {
        for (Requirement req : requirements) {
            // 1. 检查有效期
            if (!isEffective(date, req)) {
                continue;
            }

            // 2. 检查重复维度
            if (!matchesRepeatMode(date, req)) {
                continue;
            }

            // 3. 根据排期模式生成时刻
            List<LocalTime> times = generateTimePoints(date, req);

            for (LocalTime time : times) {
                // 4. 检查时间窗口
                if (!isInTimeWindow(time, req)) {
                    continue;
                }

                candidates.add(CandidateTimePoint.builder()
                        .date(date)
                        .time(time)
                        .requirement(req)
                        .priority(policy.getPriority())
                        .allowAdvance(policy.getAllowAdvanceMinutes())
                        .allowDelay(policy.getAllowDelayMinutes())
                        .build());
            }
        }
    }

    return candidates;
}
```

### 3.3 三种排期模式的时刻生成

```java
/**
 * 排期模式 1: 固定时间点模式
 *
 * 场景: 每天固定3个时刻执行 09:00, 14:00, 18:00
 * 配置:
 *   - scheduleMode = 1
 *   - timePoints = [09:00, 14:00, 18:00]
 *
 * 算法: 直接返回配置的 timePoints
 */
public List<LocalTime> generateFixedTimePoints(Requirement req) {
    return req.getTimePoints(); // 直接返回用户配置的时刻
}

/**
 * 排期模式 2: 间隔执行模式
 *
 * 场景: 国标要求每2小时完成一次巡检
 * 配置:
 *   - scheduleMode = 2
 *   - taskCycleMinutes = 120      // 任务周期（开始-开始）
 *   - taskGapMinutes = 30         // 任务间隔（完成-开始）
 *   - windowStartTime = 08:00
 *   - windowEndTime = 20:00
 *   - anchorTime = 08:00          // 每日基准时间
 *
 * 算法:
 *   1. 以 anchorTime 为起点
 *   2. 每隔 taskCycleMinutes 生成一个时刻
 *   3. 超出 windowEndTime 停止
 *   4. 生成结果: [08:00, 10:00, 12:00, 14:00, 16:00, 18:00, 20:00]
 */
public List<LocalTime> generateIntervalTimePoints(Requirement req) {
    List<LocalTime> times = new ArrayList<>();
    LocalTime current = req.getAnchorTime();
    LocalTime windowEnd = req.getWindowEndTime();

    while (!current.isAfter(windowEnd)) {
        times.add(current);
        current = current.plusMinutes(req.getTaskCycleMinutes());
    }

    return times;
}

/**
 * 排期模式 3: 自动编排模式
 *
 * 场景: 用户只要求每天执行3次，由算法自动安排时刻
 * 配置:
 *   - scheduleMode = 3
 *   - dailyExecutionCount = 3      // 每日执行次数
 *   - windowStartTime = 08:00
 *   - windowEndTime = 20:00
 *   - minExecutionsPerDay = 12    // 可选: 最少次数（国标）
 *   - maxExecutionsPerDay = 6     // 可选: 最多次数（限流）
 *
 * 算法:
 *   1. 计算时间窗口长度: 20:00 - 08:00 = 12小时 = 720分钟
 *   2. 计算均匀间隔: 720 / (3 + 1) = 180分钟
 *   3. 生成时刻: [08:00, 11:00, 14:00, 17:00, 20:00]
 *   4. 取中间3个: [08:00 偏移后...]
 *
 * 智能策略（考虑 policy）:
 *   - 高峰期优先: 工作时间多安排
 *   - 避峰策略: 避开用餐时间
 *   - 均匀分布: 最大化覆盖时间窗口
 */
public List<LocalTime> generateAutoTimePoints(Requirement req, SchedulePolicy policy) {
    int count = req.getDailyExecutionCount();
    LocalTime windowStart = req.getWindowStartTime();
    LocalTime windowEnd = req.getWindowEndTime();

    // 智能算法计算均匀分布时刻
    List<LocalTime> times = calculateUniformDistribution(
            windowStart, windowEnd, count, policy);

    return times;
}
```

## 五、冲突处理策略

```java
/**
 * 冲突处理 - 由 Policy.conflictStrategy 控制
 *
 * 冲突场景: 两个任务都想在 09:00 执行
 */
public class ConflictResolver {

    /**
     * 策略1: 跳过（Skip）
     * 优先级高的任务执行，低优先级的跳过
     */
    public void resolveBySkip(List<CandidateTimePoint> candidates) {
        candidates.sort(Comparator.comparing(CandidateTimePoint::getPriority));

        Set<String> usedSlots = new HashSet<>();
        for (CandidateTimePoint c : candidates) {
            String slot = c.getDate() + " " + c.getTime();
            if (usedSlots.contains(slot)) {
                c.setStatus(ScheduleStatus.SKIPPED);
                c.setSkipReason("与高优先级任务冲突");
            } else {
                usedSlots.add(slot);
                c.setStatus(ScheduleStatus.CONFIRMED);
            }
        }
    }

    /**
     * 策略2: 顺延（Postpone）
     * 冲突的任务顺延到下一个可用时间窗口
     */
    public void resolveByPostpone(List<CandidateTimePoint> candidates, Requirement req) {
        // 顺延逻辑: 找到下一个空闲时间点
        for (CandidateTimePoint c : candidates) {
            if (c.hasConflict()) {
                LocalTime nextSlot = findNextAvailableSlot(c, req);
                c.setTime(nextSlot);
                c.setStatus(ScheduleStatus.POSTPONED);
            }
        }
    }

    /**
     * 策略3: 拆分（Split）
     * 将高频率任务拆分为多个低频率任务
     */
    public void resolveBySplit(List<CandidateTimePoint> candidates, SchedulePolicy policy) {
        // 拆分逻辑: 减少每次执行范围
        for (CandidateTimePoint c : candidates) {
            if (c.hasConflict()) {
                // 分配给不同资源执行
                c.setAssignedRobot(null); // 留给调度器分配
                c.setStatus(ScheduleStatus.PENDING_RESOURCE);
            }
        }
    }
}
```

## 六、多任务编排 - 资源冲突分析

### 6.1 资源冲突的典型场景

### 6.2 冲突类型分类

| 冲突类型 | 定义 | 检测方法 | 处理优先级 |
|----------|------|----------|------------|
| **时间冲突** | 多个任务计划在同一时刻执行 | 比较 scheduledTime | P1 |
| **资源冲突** | 多个任务需要同一资源 | 比较 resourcePool | P2 |
| **双重冲突** | 时间+资源同时冲突 | 联合检测 | P0 |
| **容量冲突** | 任务需要的机器人数量超过可用数量 | 资源池容量检查 | P0 |

### 6.3 资源冲突检测算法

```java
/**
 * 资源冲突检测器
 *
 * 在多任务编排时，需要检测：
 * 1. 时间点是否已被占用
 * 2. 资源是否可用
 * 3. 资源池容量是否足够
 */
public class ResourceConflictDetector {

    /**
     * 检测资源冲突
     *
     * @param candidate      待检测的候选时间点
     * @param context       编排上下文（包含已确认的计划）
     * @param resourcePool  任务需要的资源池
     * @return 冲突检测结果
     */
    public ConflictResult detectConflict(
            CandidateTimePoint candidate,
            ScheduleContext context,
            ResourcePool resourcePool) {

        LocalDateTime candidateTime = candidate.getDateTime();
        List<Long> requiredRobots = resourcePool.getRobotIds();

        // 1. 检测时间点是否被占用
        boolean timeOccupied = context.isTimeSlotOccupied(candidateTime);

        // 2. 检测所需资源是否可用
        List<Long> unavailableRobots = new ArrayList<>();
        for (Long robotId : requiredRobots) {
            if (!context.isRobotAvailable(robotId, candidateTime)) {
                unavailableRobots.add(robotId);
            }
        }

        // 3. 检测资源池容量
        int requiredCount = resourcePool.getMinRobotCount();
        int availableCount = context.countAvailableRobots(
                resourcePool.getRobotType(), candidateTime);
        boolean capacitySufficient = availableCount >= requiredCount;

        // 构建冲突结果
        return ConflictResult.builder()
                .hasTimeConflict(timeOccupied)
                .hasResourceConflict(!unavailableRobots.isEmpty())
                .hasCapacityConflict(!capacitySufficient)
                .unavailableRobots(unavailableRobots)
                .availableCount(availableCount)
                .requiredCount(requiredCount)
                .build();
    }

    /**
     * 检测资源冲突（考虑执行时长）
     *
     * 场景: 任务A 09:00开始，预计完成时间10:30
     *       任务B 10:00开始，需要机器人1
     *       → 即使10:00时任务A还没完成，仍然冲突
     */
    public ConflictResult detectConflictWithDuration(
            CandidateTimePoint candidate,
            ScheduleContext context,
            ResourcePool resourcePool,
            Duration estimatedDuration) {

        LocalDateTime startTime = candidate.getDateTime();
        LocalDateTime endTime = startTime.plus(estimatedDuration);

        // 检查整个执行时段内资源是否可用
        List<Long> unavailableRobots = new ArrayList<>();
        for (Long robotId : resourcePool.getRobotIds()) {
            if (!context.isRobotAvailableDuring(robotId, startTime, endTime)) {
                unavailableRobots.add(robotId);
            }
        }

        return ConflictResult.builder()
                .hasResourceConflict(!unavailableRobots.isEmpty())
                .unavailableRobots(unavailableRobots)
                .conflictPeriodStart(startTime)
                .conflictPeriodEnd(endTime)
                .build();
    }
}
```

#### 策略一：按优先级抢占（Preempt by Priority）

```
┌─────────────────────────────────────────────────────────────────────┐
│                    策略一：按优先级抢占                               │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  规则: 高优先级任务优先占用资源，低优先级任务让步                     │
│                                                                      │
│  场景:                                                               │
│  ┌─────────────────────────────────────────────────────────┐        │
│  │ 时间   │ 任务A(优先级1)    │ 任务B(优先级3)              │        │
│  ├─────────────────────────────────────────────────────────┤        │
│  │ 09:00 │ ✓ 获得机器人1     │ ✗ 被抢占，需要重新编排      │        │
│  │ 10:00 │ ✓ 释放机器人1     │ ✓ 获得机器人1              │        │
│  └─────────────────────────────────────────────────────────┘        │
│                                                                      │
│  结果: 任务A按时执行，任务B顺延到10:00                               │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

```java
/**
 * 策略一：按优先级抢占
 */
public class PreemptByPriorityStrategy implements ResourceConflictStrategy {

    @Override
    public List<SchedulePlan> resolve(
            List<CandidateTimePoint> candidates,
            ScheduleContext context) {

        // 1. 按优先级排序（数字越小优先级越高）
        candidates.sort(Comparator.comparing(CandidateTimePoint::getPriority));

        List<SchedulePlan> confirmed = new ArrayList<>();
        List<CandidateTimePoint> pending = new ArrayList<>();

        for (CandidateTimePoint candidate : candidates) {
            // 检测资源是否可用
            ConflictResult conflict = conflictDetector.detectConflict(
                    candidate, context, candidate.getResourcePool());

            if (!conflict.hasAnyConflict()) {
                // 资源可用，确认计划
                confirmed.add(toPlan(candidate));
                context.markResourceOccupied(candidate);
            } else {
                // 资源被占用，检查是否可以抢占
                CandidateTimePoint occupyingTask =
                        context.getOccupyingTask(candidate.getTime(),
                                candidate.getResourcePool());

                if (occupyingTask != null
                        && candidate.getPriority() < occupyingTask.getPriority()) {
                    // 可以抢占：当前任务优先级更高
                    context.cancelPlan(occupyingTask);
                    confirmed.add(toPlan(candidate));
                    context.markResourceOccupied(candidate);
                    occupyingTask.setStatus(ScheduleStatus.REORDERED);
                    pending.add(occupyingTask);
                } else {
                    // 不可抢占：加入待处理队列
                    pending.add(candidate);
                }
            }
        }

        // 递归处理待处理的任务
        if (!pending.isEmpty()) {
            List<SchedulePlan> reordered = resolveWithDelay(pending, context);
            confirmed.addAll(reordered);
        }

        return confirmed;
    }
}
```

```java
/**
 * 策略二：资源池隔离
 *
 * 前提：任务必须配置了 resourcePool（专属资源池）
 */
public class ResourcePoolIsolationStrategy implements ResourceConflictStrategy {

    @Override
    public List<SchedulePlan> resolve(
            List<CandidateTimePoint> candidates,
            ScheduleContext context) {

        List<SchedulePlan> confirmed = new ArrayList<>();

        for (CandidateTimePoint candidate : candidates) {
            ResourcePool pool = candidate.getResourcePool();

            // 检查是否配置了专属资源池
            if (pool == null || pool.getRobotIds().isEmpty()) {
                // 未配置资源池，使用默认策略
                continue;

                confirmed.add(toPlan(candidate));
                context.markResourceOccupied(candidate);
            } else {
                // 资源池内冲突，需要在池内解决
                confirmed.addAll(resolveWithinPool(candidate, context, pool));
            }
        }

        return confirmed;
    }
}
```

```java
/**
 * 策略三：时间窗口错峰
 *
 * 当同一时刻多个任务争抢同一资源时，自动计算最佳错峰时间
 */
public class TimeWindowStaggeringStrategy implements ResourceConflictStrategy {

    private static final int STAGGER_INTERVAL_MINUTES = 30; // 默认错峰间隔

    @Override
    public List<SchedulePlan> resolve(
            List<CandidateTimePoint> candidates,
            ScheduleContext context) {

        List<SchedulePlan> confirmed = new ArrayList<>();

        // 按时间分组
        Map<LocalDateTime, List<CandidateTimePoint>> byTime =
                candidates.stream()
                        .collect(Collectors.groupingBy(CandidateTimePoint::getDateTime));

        for (Map.Entry<LocalDateTime, List<CandidateTimePoint>> entry : byTime.entrySet()) {
            LocalDateTime time = entry.getKey();
            List<CandidateTimePoint> tasksAtTime = entry.getValue();

            if (tasksAtTime.size() == 1) {
                // 只有一个任务，直接尝试编排
                CandidateTimePoint task = tasksAtTime.get(0);
                if (tryConfirm(task, context)) {
                    confirmed.add(toPlan(task));
                }
            } else {
                // 多个任务同时需要编排
                confirmed.addAll(resolveMultipleTasks(
                        tasksAtTime, time, context));
            }
        }

        return confirmed;
    }

    /**
     * 处理多个任务同时需要同一资源的情况
     */
    private List<SchedulePlan> resolveMultipleTasks(
            List<CandidateTimePoint> tasks,
            LocalDateTime baseTime,
            ScheduleContext context) {

        List<SchedulePlan> confirmed = new ArrayList<>();

        // 按优先级排序
        tasks.sort(Comparator.comparing(CandidateTimePoint::getPriority));

        int staggerOffset = 0;
        for (CandidateTimePoint task : tasks) {
            // 尝试在不同时间点安排
            LocalDateTime adjustedTime = findNextAvailableSlot(
                    baseTime.plusMinutes(staggerOffset),
                    task,
                    context);

            if (adjustedTime != null) {
                task.setDateTime(adjustedTime);
                if (tryConfirm(task, context)) {
                    confirmed.add(toPlan(task));
                }
            }

            // 累加错峰间隔
            staggerOffset += STAGGER_INTERVAL_MINUTES;
        }

        return confirmed;
    }

    /**
     * 查找下一个可用时间槽（考虑任务执行时长）
     */
    private LocalDateTime findNextAvailableSlot(
            LocalDateTime startTime,
            CandidateTimePoint task,
            ScheduleContext context) {

        Duration duration = task.getEstimatedDuration();
        LocalDateTime maxSearchTime = startTime.plusHours(4); // 最多搜索4小时

        LocalDateTime current = startTime;
        while (current.isBefore(maxSearchTime)) {
            LocalDateTime endTime = current.plus(duration);

            // 检查时间窗口约束
            if (!isWithinTimeWindow(current, task.getRequirement())) {
                current = current.plusDays(1).withHour(8); // 跳到下一天8:00
                continue;
            }

            // 检查资源是否可用（考虑执行时长）
            if (context.isResourceAvailableDuring(
                    task.getResourcePool(), current, endTime)) {
                return current;
            }

            current = current.plusMinutes(STAGGER_INTERVAL_MINUTES);
        }

        return null; // 无法找到可用时间槽
    }
}
```

#### 策略四：资源弹性分配（Flexible Resource Allocation）

```
┌─────────────────────────────────────────────────────────────────────┐
│                    策略四：资源弹性分配                               │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  规则: 当首选资源不可用时，自动分配替代资源                          │
│                                                                      │
│  场景: 任务A首选机器人1，但机器人1被占用                             │
│                                                                      │
│  解决: 按优先级尝试机器人1 → 机器人2 → 机器人3                       │
│                                                                      │
│  ┌─────────────────────────────────────────────────────────┐        │
│  │ ResourcePool: {                                         │        │
│  │   primaryRobots: [1, 2, 3],  // 首选                    │        │

│  │   anyAvailable: true          // 是否接受任意可用资源    │        │
│  │ }                                                       │        │

│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

```java
/**
 * 策略四：资源弹性分配
 */
public class FlexibleResourceAllocationStrategy implements ResourceConflictStrategy {

    @Override
    public List<SchedulePlan> resolve(
            List<CandidateTimePoint> candidates,
            ScheduleContext context) {

        List<SchedulePlan> confirmed = new ArrayList<>();

        for (CandidateTimePoint candidate : candidates) {
            SchedulePlan plan = tryAllocateResource(candidate, context);
            if (plan != null) {
                confirmed.add(plan);
            } else {
                // 无法分配资源，标记为待调度
                candidate.setStatus(ScheduleStatus.PENDING_RESOURCE);
            }
        }

        return confirmed;
    }

    /**
     * 尝试分配资源（按优先级尝试多个备选方案）
     */
    private SchedulePlan tryAllocateResource(
            CandidateTimePoint candidate,
            ScheduleContext context) {

        ResourcePool pool = candidate.getResourcePool();
        if (pool == null) {
            return null;
        }

        LocalDateTime startTime = candidate.getDateTime();
        Duration duration = candidate.getEstimatedDuration();
        LocalDateTime endTime = startTime.plus(duration);

        // 1. 尝试首选资源
        for (Long robotId : pool.getPrimaryRobots()) {
            if (context.isRobotAvailableDuring(robotId, startTime, endTime)) {
                return allocateAndConfirm(candidate, robotId, context);
            }
        }

        // 2. 尝试备用资源
        if (pool.getFallbackRobots() != null) {
            for (Long robotId : pool.getFallbackRobots()) {
                if (context.isRobotAvailableDuring(robotId, startTime, endTime)) {
                    return allocateAndConfirm(candidate, robotId, context);
                }
            }
        }

        // 3. 允许任意可用资源
        if (Boolean.TRUE.equals(pool.getAnyAvailable())) {
            List<Long> availableRobots = context.findAvailableRobots(
                    pool.getRobotType(), startTime, endTime);
            if (!availableRobots.isEmpty()) {
                return allocateAndConfirm(candidate, availableRobots.get(0), context);
            }
        }

        return null; // 所有资源都不可用
    }

    private SchedulePlan allocateAndConfirm(
            CandidateTimePoint candidate,
            Long robotId,
            ScheduleContext context) {

        candidate.setAssignedRobotId(robotId);
        SchedulePlan plan = toPlan(candidate);
        context.markResourceOccupied(candidate);
        return plan;
    }
}
```

### 6.5 时间冲突 + 资源冲突 联合处理

```
┌─────────────────────────────────────────────────────────────────────┐

│  场景:                                                               │
│  ┌─────────────────────────────────────────────────────────┐        │
│  │ 09:00 │ 任务A: 优先级1, 需要机器人1                     │        │
│  │ 09:00 │ 任务B: 优先级2, 需要机器人1                     │        │
│  │ 09:00 │ 任务C: 优先级3, 需要机器人2                     │        │

│                                                                      │
│  处理流程:                                                           │
│  1. 优先级排序: A > D > B > C                                        │
│  2. 任务A获得机器人1，09:00执行                                       │
│  3. 任务D无法在09:00执行（机器人1被占用），尝试09:30                  │
│  4. 任务B无法在09:00执行（机器人1被占用），尝试其他时间               │
│  5. 任务C获得机器人2，09:00执行                                       │
│                                                                      │
│  最终结果:                                                           │
│  ┌─────────────────────────────────────────────────────────┐        │
│  │ 09:00 │ 任务A → 机器人1                                 │        │
│  │ 09:00 │ 任务C → 机器人2                                 │        │
│  │ 09:30 │ 任务D → 机器人1 (任务A完成后)                   │        │
│  │ 10:00 │ 任务B → 待定 (需进一步编排)                     │        │
│  └─────────────────────────────────────────────────────────┘        │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

```java
/**
 * 时间冲突 + 资源冲突 联合处理器
 */
public class UnifiedConflictResolver {

    public ScheduleResult resolveAllConflicts(
            List<CandidateTimePoint> allCandidates,
            ScheduleContext context) {

        // Step 1: 优先级排序
        allCandidates.sort(Comparator
                .comparing(CandidateTimePoint::getPriority)
                .thenComparing(CandidateTimePoint::getDateTime));

        List<SchedulePlan> confirmed = new ArrayList<>();
        List<CandidateTimePoint> pending = new ArrayList<>();

        for (CandidateTimePoint candidate : allCandidates) {
            // Step 2: 检测时间冲突
            boolean hasTimeConflict = context.isTimeSlotOccupied(
                    candidate.getDateTime());

            // Step 3: 检测资源冲突
            ConflictResult resourceConflict = conflictDetector.detectConflict(
                    candidate, context, candidate.getResourcePool());

            if (!hasTimeConflict && !resourceConflict.hasAnyConflict()) {
                // 无冲突，直接确认
                confirmed.add(confirmPlan(candidate, context));
            } else if (hasTimeConflict && !resourceConflict.hasAnyConflict()) {
                // 只有时间冲突，尝试时间调整
                SchedulePlan plan = tryTimeAdjustment(candidate, context);
                if (plan != null) {
                    confirmed.add(plan);
                } else {
                    pending.add(candidate);
                }
            } else if (!hasTimeConflict && resourceConflict.hasAnyConflict()) {
                // 只有资源冲突，尝试资源分配
                SchedulePlan plan = tryResourceAllocation(candidate, context);
                if (plan != null) {
                    confirmed.add(plan);
                } else {
                    pending.add(candidate);
                }
            } else {
                // 时间+资源双重冲突
                SchedulePlan plan = tryJointResolution(candidate, context);
                if (plan != null) {
                    confirmed.add(plan);
                } else {
                    pending.add(candidate);
                }
            }
        }

        // Step 4: 处理待定任务
        if (!pending.isEmpty()) {
            confirmed.addAll(retryPendingTasks(pending, context));
        }

        return buildResult(confirmed, pending);
    }

    /**
     * 时间+资源双重冲突联合解决
     */
    private SchedulePlan tryJointResolution(
            CandidateTimePoint candidate,
            ScheduleContext context) {

        Requirement req = candidate.getRequirement();
        Duration duration = candidate.getEstimatedDuration();

        // 1. 获取允许的提前/延后范围
        int allowAdvance = candidate.getAllowAdvanceMinutes();
        int allowDelay = candidate.getAllowDelayMinutes();

        // 2. 在时间范围内搜索可用时间点
        LocalDateTime baseTime = candidate.getDateTime();
        LocalDateTime earliest = baseTime.minusMinutes(allowAdvance);
        LocalDateTime latest = baseTime.plusMinutes(allowDelay);

        LocalDateTime current = earliest;
        while (!current.isAfter(latest)) {
            LocalDateTime endTime = current.plus(duration);

            // 检查时间窗口约束
            if (!isWithinTimeWindow(current, req)) {
                current = current.plusMinutes(30);
                continue;
            }

            // 检查时间是否被占用
            if (context.isTimeSlotOccupied(current)) {
                current = current.plusMinutes(30);
                continue;
            }

            // 检查资源是否可用
            ConflictResult conflict = conflictDetector.detectConflictWithDuration(
                    CandidateTimePoint.builder()
                            .dateTime(current)
                            .requirement(req)
                            .resourcePool(candidate.getResourcePool())
                            .build(),
                    context,
                    candidate.getResourcePool(),
                    duration);

            if (!conflict.hasAnyConflict()) {
                // 找到可用时间点和资源
                candidate.setDateTime(current);
                return confirmPlan(candidate, context);
            }

            current = current.plusMinutes(30);
        }

        return null; // 无法解决
    }
}
```

```java
/**
 * 编排上下文
 *
 * 维护编排过程中的所有状态，用于冲突检测
 */
public class ScheduleContext {

    // 已确认的计划
    private Map<Long, SchedulePlan> confirmedPlans = new HashMap<>();

    // 时间槽占用情况: key = "date@time", value = taskId
    private Map<String, Long> timeSlotOccupancy = new HashMap<>();

    // 资源占用情况: key = robotId, value = List<时间段>
    private Map<Long, List<TimeRange>> resourceOccupancy = new HashMap<>();

    // 资源池可用机器人数量
    private Map<String, Integer> availableRobotCount = new HashMap<>();

    /**
     * 标记时间槽被占用
     */
    public void markTimeSlotOccupied(LocalDateTime time, Long taskId) {
        String key = formatTimeSlotKey(time);
        timeSlotOccupancy.put(key, taskId);
    }

    /**
     * 检查时间槽是否被占用
     */
    public boolean isTimeSlotOccupied(LocalDateTime time) {
        String key = formatTimeSlotKey(time);
        return timeSlotOccupancy.containsKey(key);
    }

    /**
     * 标记资源被占用（考虑执行时长）
     */
    public void markResourceOccupied(Long robotId, LocalDateTime start, LocalDateTime end) {
        resourceOccupancy.computeIfAbsent(robotId, k -> new ArrayList<>())
                .add(new TimeRange(start, end));
    }

    /**
     * 检查资源在指定时段是否可用
     */
    public boolean isRobotAvailableDuring(
            Long robotId, LocalDateTime start, LocalDateTime end) {

        List<TimeRange> ranges = resourceOccupancy.get(robotId);
        if (ranges == null || ranges.isEmpty()) {
            return true;
        }

        for (TimeRange range : ranges) {
            if (rangesOverlap(start, end, range.getStart(), range.getEnd())) {
                return false;
            }
        }
        return true;
    }

    /**
     * 统计指定时段的可用机器人数量
     */
    public int countAvailableRobots(String robotType, LocalDateTime time) {
        int total = availableRobotCount.getOrDefault(robotType, 0);
        int occupied = 0;

        for (Map.Entry<Long, List<TimeRange>> entry : resourceOccupancy.entrySet()) {
            for (TimeRange range : entry.getValue()) {
                if (range.contains(time)) {
                    occupied++;
                    break;
                }
            }
        }

        return total - occupied;
    }

    private boolean rangesOverlap(LocalDateTime start1, LocalDateTime end1,
                                  LocalDateTime start2, LocalDateTime end2) {
        return start1.isBefore(end2) && start2.isBefore(end1);
    }
}
```

## 八、关键算法伪代码汇总

### 8.1 完整编排流程

```java
public class ScheduleEngine {

    public ScheduleResult orchestrate(ScheduleRequest request) {
        LocalDate startDate = request.getStartDate();
        LocalDate endDate = request.getEndDate();

        // 1. 加载所有活跃任务及其配置
        List<InspectionTask> tasks = taskMapper.selectActiveTasks();
        Map<Long, Requirement> reqMap = loadRequirements(tasks);
        Map<Long, SchedulePolicy> policyMap = loadPolicies(tasks);

        // 2. 初始化编排上下文
        ScheduleContext context = new ScheduleContext();
        context.setPlans(new ArrayList<>());
        context.setUsedTimeSlots(new HashMap<>()); // key: date+" "+time

        // 3. 逐个任务生成候选点
        for (InspectionTask task : tasks) {
            Requirement req = reqMap.get(task.getScheduleReqId());
            SchedulePolicy policy = policyMap.get(task.getSchedulePolicyId());

            // 3.1 生成候选时间点
            List<CandidateTimePoint> candidates =
                    generateCandidates(task, req, startDate, endDate);

            // 3.2 校验执行次数约束
            candidates = filterByExecutionConstraints(
                    candidates, req, context.getPlans());

            // 3.3 冲突检测
            candidates = detectConflicts(candidates, context.getUsedTimeSlots());

            // 3.4 应用冲突策略
            candidates = applyConflictStrategy(candidates, policy);

            // 3.5 确认并记录
            for (CandidateTimePoint c : candidates) {
                if (c.isConfirmed()) {
                    context.addPlan(toSchedulePlan(c, task));
                    context.markSlotUsed(c.getDate(), c.getTime());
                }
            }
        }

        // 4. 返回编排结果
        return ScheduleResult.builder()
                .plans(context.getPlans())
                .totalCount(context.getPlans().size())
                .successCount(countByStatus(context.getPlans(), CONFIRMED))
                .skippedCount(countByStatus(context.getPlans(), SKIPPED))
                .build();
    }
}
```

### 8.3 重复维度检查

```java
/**
 * 检查日期是否匹配重复模式
 *
 * @param date 目标日期
 * @param req  需求配置
 * @return true-需要执行，false-跳过
 */
public boolean matchesRepeatMode(LocalDate date, Requirement req) {
    Integer repeatMode = req.getRepeatMode();

    switch (repeatMode) {
        case 1: // 一次性
            return date.equals(req.getStartDate());

        case 2: // 每日
            return true; // 每天都执行

        case 3: // 每周
            int dayOfWeek = date.getDayOfWeek().getValue(); // 1=周一, 7=周日
            return req.getWeekDays().contains(dayOfWeek);

        case 4: // 每月
            int dayOfMonth = date.getDayOfMonth();
            List<Integer> monthDays = req.getMonthDays();
            // 检查是否匹配配置的日期，或超过当月最大天数时取月末
            return monthDays.contains(dayOfMonth)
                    || (dayOfMonth == date.lengthOfMonth()
                        && monthDays.contains(31)
                        && dayOfMonth < 31);
    }

    return false;
}
```

## 十一、全局优化方案（多任务联合编排）

### 11.1 问题分析：为什么局部处理会导致全局恶化？

**核心问题**：逐个任务编排可能导致"贪心陷阱"

```
场景分析：
┌─────────────────────────────────────────────────────────────────────┐
│  贪心算法的问题                                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  假设：只有1台机器人（机器人1）                                      │
│                                                                      │
│  任务A：优先级3，允许延后60分钟                                      │
│  任务B：优先级1，允许延后60分钟                                      │
│                                                                      │
│  贪心处理（逐个编排）：                                              │
│  ┌─────────────────────────────────────────────────────────┐        │
│  │ Step 1: 编排任务A                                        │        │
│  │         尝试 09:00 → 可用 ✓                              │        │
│  │         任务A分配到 09:00，机器人1被占用至 09:45         │        │
│  │                                                                  │
│  │ Step 2: 编排任务B（优先级更高）                          │        │
│  │         尝试 09:00 → 机器人1 已被占用 ✗                  │        │
│  │         尝试 09:30 → 可用 ✓（顺延30分钟）               │        │
│  │         任务B分配到 09:30                                │        │
│  └─────────────────────────────────────────────────────────┘        │
│                                                                      │
│  问题：任务B延后了30分钟才能执行                                      │
│                                                                      │
│  ──────────────────────────────────────────────────────────────     │
│                                                                      │
│  全局最优处理（全局视角）：                                           │
│  ┌─────────────────────────────────────────────────────────┐        │
│  │ 分析所有任务的时间窗口：                                    │        │
│  │ - 任务A: 08:00-18:00 可选                               │        │
│  │ - 任务B: 08:00-18:00 可选                               │        │
│  │                                                              │        │
│  │ 评估最优分配方案：                                          │        │
│  │ - 方案A: 任务A→09:00, 任务B→09:30 （总延后30分钟）       │        │
│  │ - 方案B: 任务A→10:00, 任务B→09:00 （总延后0分钟）        │        │
│  │                                                              │        │
│  │ 方案B更优：任务B优先级更高，应优先分配最佳时间             │        │
│  └─────────────────────────────────────────────────────────┘        │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

**结论**：逐个任务处理（局部最优）可能导致整体结果不优。全局优化需要：

1. **先收集所有任务需求**
2. **构建全局资源可用性矩阵**
3. **基于全局视图进行联合优化分配**

### 11.2 全局资源可用性矩阵

```java
/**
 * 全局资源可用性矩阵
 *
 * <p>在编排开始前构建，记录所有资源在各时间段的可用性状态</p>
 */
public class ResourceAvailabilityMatrix {

    // 时间粒度（分钟）
    private static final int TIME_GRANULARITY = 15;

    // 矩阵结构: 时间段 → (机器人ID → 是否可用)
    private Map<LocalDateTime, Map<Long, Boolean>> matrix;

    // 编排周期
    private LocalDateTime startTime;
    private LocalDateTime endTime;

    /**
     * 初始化矩阵
     */
    public void initialize(LocalDate startDate, LocalDate endDate,
                           List<Robot> robots) {
        this.matrix = new HashMap<>();

        LocalDateTime current = startDate.atTime(0, 0);
        this.endTime = endDate.plusDays(1).atTime(0, 0);

        while (current.isBefore(endTime)) {
            Map<Long, Boolean> robotStatus = new HashMap<>();
            for (Robot robot : robots) {
                robotStatus.put(robot.getId(), true);
            }
            matrix.put(current, robotStatus);
            current = current.plusMinutes(TIME_GRANULARITY);
        }
    }

    /**
     * 标记资源在指定时段被占用
     */
    public void markOccupied(Long robotId, LocalDateTime start,
                              LocalDateTime end, String reason) {
        LocalDateTime current = start;
        while (current.isBefore(end)) {
            Map<Long, Boolean> slot = matrix.get(current);
            if (slot != null) {
                slot.put(robotId, false);
            }
            current = current.plusMinutes(TIME_GRANULARITY);
        }
    }

    /**
     * 查询资源在指定时段是否完全可用
     */
    public boolean isAvailable(Long robotId, LocalDateTime start,
                                Duration duration) {
        LocalDateTime end = start.plus(duration);
        LocalDateTime current = start;

        while (current.isBefore(end)) {
            Map<Long, Boolean> slot = matrix.get(current);
            if (slot == null || !Boolean.TRUE.equals(slot.get(robotId))) {
                return false;
            }
            current = current.plusMinutes(TIME_GRANULARITY);
        }
        return true;
    }

    /**
     * 查找下一个可用时间点
     */
    public LocalDateTime findNextAvailableSlot(Long robotId,
                                                LocalDateTime earliestTime,
                                                Duration duration,
                                                LocalDateTime maxSearchTime) {
        LocalDateTime current = earliestTime;
        while (current.isBefore(maxSearchTime)) {
            if (isAvailable(robotId, current, duration)) {
                return current;
            }
            current = current.plusMinutes(TIME_GRANULARITY);
        }
        return null;
    }
}
```

```java
/**
 * Step 0: 数据准备阶段

 * <p>此阶段进行静态校验，确保配置层面没有矛盾</p>
 */
public class DataPreparationService {

    /**
     * 数据准备
     */
    public OrchestrationData prepare(OrchestrationRequest request) {
        OrchestrationData data = new OrchestrationData();

        // 1. 加载任务及其配置
        List<InspectionTask> tasks = taskMapper.selectActiveTasks();
        data.setTasks(tasks);

        // 2. 加载 Requirement 和 Policy
        Map<Long, Requirement> reqMap = loadRequirements(tasks);
        Map<Long, SchedulePolicy> policyMap = loadPolicies(tasks);
        data.setRequirementMap(reqMap);
        data.setPolicyMap(policyMap);

        // ========== 关键：需求冲突检测（Step 0 核心） ==========
        RequirementConflictReport report = detectRequirementConflicts(reqMap, tasks);
        data.setRequirementConflictReport(report);

        if (report.hasBlockingConflicts()) {
            // 存在阻塞性冲突，无法编排
            throw new RequirementConflictException(report);
        }

        // 3. 加载资源
        List<Robot> robots = robotMapper.selectAllActiveRobots();
        data.setRobots(robots);

        // 4. 构建资源可用性矩阵
        ResourceAvailabilityMatrix matrix = buildAvailabilityMatrix(
                request.getStartDate(), request.getEndDate(), robots);
        data.setAvailabilityMatrix(matrix);

        return data;
    }

    /**
     * Requirement 需求冲突检测（静态校验）
     *
     * <p>在编排开始前检测配置层面的矛盾</p>
     */
    public RequirementConflictReport detectRequirementConflicts(
            Map<Long, Requirement> reqMap,
            List<InspectionTask> tasks) {

        RequirementConflictReport report = new RequirementConflictReport();

        for (InspectionTask task : tasks) {
            Requirement req = reqMap.get(task.getScheduleReqId());
            if (req == null) continue;

            List<String> conflicts = new ArrayList<>();
            String taskInfo = "任务[" + task.getTaskName() + "] ";

            // 冲突1: min > max（每日）
            if (req.getMinExecutionsPerDay() != null
                    && req.getMaxExecutionsPerDay() != null
                    && req.getMinExecutionsPerDay() > req.getMaxExecutionsPerDay()) {
                conflicts.add(taskInfo + "每日执行次数矛盾：最少"
                        + req.getMinExecutionsPerDay() + "次 > 最多"
                        + req.getMaxExecutionsPerDay() + "次");
            }

            // 冲突2: min > max（每周）
            if (req.getMinExecutionsPerWeek() != null
                    && req.getMaxExecutionsPerWeek() != null
                    && req.getMinExecutionsPerWeek() > req.getMaxExecutionsPerWeek()) {
                conflicts.add(taskInfo + "每周执行次数矛盾");
            }

            // 冲突3: 间隔执行模式计算次数 < 国标要求
            if (req.getScheduleMode() == 2
                    && req.getTaskCycleMinutes() != null) {
                int calculatedDaily = calculateDailyCountByInterval(req);
                if (req.getMinExecutionsPerDay() != null
                        && calculatedDaily < req.getMinExecutionsPerDay()) {
                    conflicts.add(taskInfo + "间隔执行无法满足国标要求："
                            + "间隔" + req.getTaskCycleMinutes() + "分钟"
                            + "每天最多" + calculatedDaily + "次"
                            + "但要求最少" + req.getMinExecutionsPerDay() + "次");
                }
            }

            // 冲突4: 时间窗口宽度不足
            if (req.getWindowStartTime() != null
                    && req.getWindowEndTime() != null) {
                long windowMinutes = Duration.between(
                        req.getWindowStartTime(), req.getWindowEndTime()).toMinutes();
                if (req.getScheduleMode() == 2
                        && req.getTaskCycleMinutes() != null) {
                    int calculatedDaily = calculateDailyCountByInterval(req);
                    if (calculatedDaily > 0 && windowMinutes < calculatedDaily * req.getTaskCycleMinutes()) {
                        conflicts.add(taskInfo + "时间窗口宽度不足："
                                + windowMinutes + "分钟无法容纳"
                                + calculatedDaily + "次执行");
                    }
                }
            }

            if (!conflicts.isEmpty()) {
                report.addConflict(task.getId(), conflicts);
            }
        }

        return report;
    }
}
```

```
┌─────────────────────────────────────────────────────────────────────┐
│                   全局优化分配算法                                   │
├─────────────────────────────────────────────────────────────────────┤

│  │  • 每个任务至少分配一个时间点                                 │  │

│                                                                      │
│  代价计算公式：                                                      │
│  ┌──────────────────────────────────────────────────────────────┐  │

│  │                                                              │  │
│  │ 优先级权重：                                                  │  │
│  │ • 优先级1（最高）: 权重 = 10                                │  │
│  │ • 优先级2（高）:   权重 = 5                                 │  │
│  │ • 优先级3（普通）: 权重 = 2                                 │  │
│  │ • 优先级4（低）:   权重 = 1                                 │  │
│  │                                                              │  │
│  │ 目的：高优先级任务应优先获得最优时间，减少调整代价           │  │
│  └──────────────────────────────────────────────────────────────┘  │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```

```java
/**
 * 全局优化分配器
 *
 * <p>基于冲突图和资源可用性矩阵，进行全局最优分配</p>
 */
public class GlobalOptimalAllocator {

    private static final Map<Integer, Double> PRIORITY_WEIGHTS = Map.of(
            1, 10.0,  // 最高优先级
            2, 5.0,
            3, 2.0,
            4, 1.0    // 最低优先级
    );

    private final ResourceAvailabilityMatrix matrix;

    public GlobalOptimalAllocator(ResourceAvailabilityMatrix matrix) {
        this.matrix = matrix;
    }

    /**
     * 全局最优分配
     */
    public AllocationResult allocate(List<CandidateTimePoint> candidates) {
        // 1. 按优先级排序（高优先级优先分配）
        List<CandidateTimePoint> sorted = candidates.stream()
                .sorted(Comparator
                        .comparing(CandidateTimePoint::getPriority)
                        .thenComparing(c -> Math.abs(c.getAdjustmentOffset())))
                .collect(Collectors.toList());

        List<CandidateTimePoint> confirmed = new ArrayList<>();
        List<CandidateTimePoint> failed = new ArrayList<>();

        // 2. 贪心分配（由于已排序，贪心即为近似最优）
        for (CandidateTimePoint candidate : sorted) {
            AllocationDecision decision = tryAllocate(candidate, confirmed);

            if (decision.isSuccess()) {
                confirmed.add(decision.getConfirmedCandidate());
            } else {
                failed.add(candidate);
            }
        }

        return AllocationResult.builder()
                .confirmed(confirmed)
                .failed(failed)
                .totalCost(calculateTotalCost(confirmed))
                .build();
    }

    /**
     * 尝试分配一个候选点
     */
    private AllocationDecision tryAllocate(CandidateTimePoint candidate,
                                            List<CandidateTimePoint> confirmed) {

        ResourcePool pool = candidate.getResourcePool();
        Duration duration = candidate.getEstimatedDuration();
        LocalDateTime adjustedTime = candidate.getAdjustedTime();

        // 获取候选资源列表
        List<Long> candidateRobots = pool != null ? pool.getRobotIds() : List.of();

        // 收集已确认计划中该任务的资源分配
        List<Long> alreadyAssigned = confirmed.stream()
                .filter(c -> c.getTaskId().equals(candidate.getTaskId()))
                .map(CandidateTimePoint::getAssignedRobotId)
                .filter(Objects::nonNull)
                .collect(Collectors.toList());

        // 过滤掉已被同一任务占用的资源
        List<Long> availableRobots = candidateRobots.stream()
                .filter(id -> !alreadyAssigned.contains(id))
                .collect(Collectors.toList());

        // 尝试为每个资源找到最佳时间点
        List<AllocationOption> options = new ArrayList<>();

        for (Long robotId : availableRobots) {
            // 检查是否可用
            if (matrix.isAvailable(robotId, adjustedTime, duration)) {
                double cost = calculateCost(candidate, adjustedTime);
                options.add(new AllocationOption(robotId, adjustedTime, cost));
            }

            // 尝试在允许范围内滑动时间（延后）
            for (int offset = 15;
                 offset <= candidate.getPolicy().getAllowDelayMinutes();
                 offset += 15) {
                LocalDateTime slidTime = adjustedTime.plusMinutes(offset);
                if (matrix.isAvailable(robotId, slidTime, duration)) {
                    double cost = calculateCost(candidate, slidTime);
                    options.add(new AllocationOption(robotId, slidTime, cost));
                }
            }

            // 尝试提前
            for (int offset = 15;
                 offset <= candidate.getPolicy().getAllowAdvanceMinutes();
                 offset += 15) {
                LocalDateTime slidTime = adjustedTime.minusMinutes(offset);
                if (matrix.isAvailable(robotId, slidTime, duration)) {
                    double cost = calculateCost(candidate, slidTime);
                    options.add(new AllocationOption(robotId, slidTime, cost));
                }
            }
        }

        // 选择代价最小的方案
        if (options.isEmpty()) {
            return AllocationDecision.failure("没有可用的资源");
        }

        AllocationOption best = options.stream()
                .min(Comparator.comparing(AllocationOption::getCost))
                .orElseThrow();

        // 标记资源被占用
        matrix.markOccupied(
                best.getRobotId(),
                best.getTime(),
                best.getTime().plus(duration),
                "任务: " + candidate.getTaskName());

        // 更新候选点
        CandidateTimePoint confirmedCandidate = candidate.clone();
        confirmedCandidate.setAssignedRobotId(best.getRobotId());
        confirmedCandidate.setAdjustedTime(best.getTime());
        confirmedCandidate.setStatus(ScheduleStatus.CONFIRMED);

        return AllocationDecision.success(confirmedCandidate);
    }

    /**
     * 计算分配代价
     */
    private double calculateCost(CandidateTimePoint candidate, LocalDateTime time) {
        long adjustmentMinutes = Math.abs(
                Duration.between(candidate.getBaseTime(), time).toMinutes());
        double priorityWeight = PRIORITY_WEIGHTS.getOrDefault(
                candidate.getPriority(), 1.0);
        return adjustmentMinutes * priorityWeight;
    }
}
```

```java
/**
 * 迭代优化器
 *
 * <p>对未解决的冲突进行多轮迭代优化</p>
 */
public class IterativeOptimizer {

    private static final int MAX_ITERATIONS = 5;
    private static final double COST_THRESHOLD = 0.01;

    private final ResourceAvailabilityMatrix matrix;

    public IterativeOptimizer(ResourceAvailabilityMatrix matrix) {
        this.matrix = matrix;
    }

    /**
     * 迭代优化
     */
    public OptimizationResult optimize(List<CandidateTimePoint> initialCandidates) {
        List<CandidateTimePoint> current = new ArrayList<>(initialCandidates);
        double currentCost = calculateGlobalCost(current);

        OptimizationResult result = OptimizationResult.builder()
                .beforeCost(currentCost)
                .iterations(0)
                .build();

        for (int iteration = 0; iteration < MAX_ITERATIONS; iteration++) {
            // 1. 检测冲突
            List<ConflictPair> conflicts = detectAllConflicts(current);

            if (conflicts.isEmpty()) {
                result.setConverged(true);
                break;
            }

            // 2. 尝试各种优化策略
            List<OptimizationAction> actions = new ArrayList<>();

            for (ConflictPair conflict : conflicts) {
                actions.addAll(tryResourceSwap(conflict, current));
                actions.addAll(tryTimeAdjustment(conflict, current));
                actions.addAll(tryTaskReassignment(conflict, current));
            }

            // 3. 选择代价降低最多的动作
            OptimizationAction bestAction = actions.stream()
                    .filter(a -> a.getCostDelta() < -COST_THRESHOLD)
                    .min(Comparator.comparing(OptimizationAction::getCostDelta))
                    .orElse(null);

            if (bestAction == null) {
                break;
            }

            // 4. 应用最优动作
            applyAction(bestAction, current);
            result.setIterations(iteration + 1);
        }

        result.setAfterCost(calculateGlobalCost(current));
        result.setFinalCandidates(current);

        return result;
    }

    /**
     * 检测所有冲突
     */
    private List<ConflictPair> detectAllConflicts(List<CandidateTimePoint> candidates) {
        List<ConflictPair> conflicts = new ArrayList<>();

        for (int i = 0; i < candidates.size(); i++) {
            for (int j = i + 1; j < candidates.size(); j++) {
                CandidateTimePoint c1 = candidates.get(i);
                CandidateTimePoint c2 = candidates.get(j);

                if (hasTimeOverlap(c1, c2) && hasResourceOverlap(c1, c2)) {
                    conflicts.add(new ConflictPair(c1, c2));
                }
            }
        }
        return conflicts;
    }

    /**
     * 策略A: 尝试资源互换
     */
    private List<OptimizationAction> tryResourceSwap(ConflictPair conflict,
                                                      List<CandidateTimePoint> candidates) {
        List<OptimizationAction> actions = new ArrayList<>();

        CandidateTimePoint c1 = conflict.getFirst();
        CandidateTimePoint c2 = conflict.getSecond();

        if (c1.getAssignedRobotId() != null && c2.getAssignedRobotId() != null) {
            Long robot1 = c1.getAssignedRobotId();
            Long robot2 = c2.getAssignedRobotId();
            Duration d1 = c1.getEstimatedDuration();
            Duration d2 = c2.getEstimatedDuration();

            if (matrix.isAvailable(robot2, c1.getAdjustedTime(), d1) &&
                matrix.isAvailable(robot1, c2.getAdjustedTime(), d2)) {
                double newCost = calculateGlobalCostAfterSwap(candidates, c1, c2, robot2, robot1);
                double delta = newCost - calculateGlobalCost(candidates);

                actions.add(OptimizationAction.builder()
                        .type(ActionType.RESOURCE_SWAP)
                        .candidate1(c1)
                        .candidate2(c2)
                        .newRobot1(robot2)
                        .newRobot2(robot1)
                        .costDelta(delta)
                        .build());
            }
        }
        return actions;
    }

    /**
     * 策略B: 尝试时间调整
     */
    private List<OptimizationAction> tryTimeAdjustment(ConflictPair conflict,
                                                        List<CandidateTimePoint> candidates) {
        List<OptimizationAction> actions = new ArrayList<>();
        CandidateTimePoint c1 = conflict.getFirst();
        CandidateTimePoint c2 = conflict.getSecond();

        LocalDateTime base1 = c1.getAdjustedTime();
        Duration d1 = c1.getEstimatedDuration();
        Long robot1 = c1.getAssignedRobotId();

        // 尝试延后
        for (int offset = 15; offset <= c1.getPolicy().getAllowDelayMinutes(); offset += 15) {
            LocalDateTime newTime1 = base1.plusMinutes(offset);
            if (matrix.isAvailable(robot1, newTime1, d1) && !hasTimeOverlap(newTime1, d1, c2)) {
                double newCost = calculateGlobalCostAfterTimeChange(candidates, c1, newTime1);
                actions.add(OptimizationAction.builder()
                        .type(ActionType.TIME_SHIFT)
                        .candidate(c1)
                        .newTime(newTime1)
                        .costDelta(newCost - calculateGlobalCost(candidates))
                        .build());
            }
        }

        // 尝试提前
        for (int offset = 15; offset <= c1.getPolicy().getAllowAdvanceMinutes(); offset += 15) {
            LocalDateTime newTime1 = base1.minusMinutes(offset);
            if (matrix.isAvailable(robot1, newTime1, d1) && !hasTimeOverlap(newTime1, d1, c2)) {
                double newCost = calculateGlobalCostAfterTimeChange(candidates, c1, newTime1);
                actions.add(OptimizationAction.builder()
                        .type(ActionType.TIME_SHIFT)
                        .candidate(c1)
                        .newTime(newTime1)
                        .costDelta(newCost - calculateGlobalCost(candidates))
                        .build());
            }
        }

        return actions;
    }

    /**
     * 策略C: 尝试任务重新分配（低优先级让步）
     */
    private List<OptimizationAction> tryTaskReassignment(ConflictPair conflict,
                                                          List<CandidateTimePoint> candidates) {
        List<OptimizationAction> actions = new ArrayList<>();

        CandidateTimePoint highPriority = c1.getPriority() < c2.getPriority() ? c1 : c2;
        CandidateTimePoint lowPriority = highPriority == c1 ? c2 : c1;

        LocalDateTime base = lowPriority.getAdjustedTime();
        Duration duration = lowPriority.getEstimatedDuration();
        Long robot = lowPriority.getAssignedRobotId();

        LocalDateTime newTime = matrix.findNextAvailableSlot(
                base.plusMinutes(15), robot, duration, base.plusHours(4));

        if (newTime != null) {
            double newCost = calculateGlobalCostAfterTimeChange(candidates, lowPriority, newTime);
            actions.add(OptimizationAction.builder()
                    .type(ActionType.TASK_REASSIGNMENT)
                    .candidate(lowPriority)
                    .newTime(newTime)
                    .reason("延后低优先级任务")
                    .costDelta(newCost - calculateGlobalCost(candidates))
                    .build());
        }

        return actions;
    }
}
```

### 11.8 全局优化 vs 局部优化对比

| 维度 | 局部优化（逐任务） | 全局优化（联合编排） |
|------|-------------------|---------------------|
| **处理顺序** | 按任务顺序依次处理 | 先收集，后统一分配 |
| **资源视图** | 仅看当前任务的资源 | 全局资源可用性矩阵 |
| **冲突处理** | 发现冲突再解决 | 预分析冲突图，批量处理 |
| **时间调整** | 贪心调整（可能恶化全局） | 计算全局代价，择优调整 |
| **结果质量** | 可能陷入局部最优 | 接近全局最优 |
| **计算复杂度** | O(n) | O(n²) ~ O(n³) |
| **适用场景** | 任务少、资源充足 | 多任务、资源紧张 |

### 11.9 关键设计决策总结

```
┌─────────────────────────────────────────────────────────────────────┐
│                   关键设计决策                                       │
├─────────────────────────────────────────────────────────────────────┤
│                                                                      │
│  Q1: 先按 Requirement 算出候选，还是先按 Resource 分配？              │
│  A:  两者结合                                                         │
│      • 先按 Requirement 生成所有候选时间点（保留弹性范围）            │
│      • 再基于全局资源矩阵进行联合分配                                │
│                                                                      │
│  Q2: 如何判断资源在不同时间段的可用性？                              │
│  A:  构建资源可用性矩阵                                               │
│      • 维度：时间段 × 机器人                                         │
│      • 状态：可用/占用                                               │
│      • 考虑因素：已有计划、执行时长、任务间隔                        │
│                                                                      │
│  Q3: 冲突解决逻辑是什么？                                            │
│  A:  多策略组合，按优先级尝试                                        │
│      1. 优先级抢占：高优先级优先分配最优时间                        │
│      2. 资源弹性：尝试替代资源                                       │
│      3. 时间调整：在允许范围内滑动                                   │
│      4. 任务延后：低优先级任务让步                                   │
│                                                                      │
│  Q4: 算法调整冲突时是反复计算还是一次性？                            │
│  A:  迭代优化，但有限制                                              │
│      • 最大迭代次数（避免死循环）                                    │
│      • 代价收敛阈值（无明显改善则停止）                              │
│      • 策略优先级（换资源 > 调时间 > 换任务）                        │
│                                                                      │
│  Q5: 如何避免"延时10分钟就不冲突"导致全局恶化？                      │
│  A:  全局代价函数                                                    │
│      • 每次调整前计算：调整后全局代价 vs 当前全局代价                │
│      • 只采纳代价降低的操作                                          │
│      • 高优先级任务的代价权重更大（保护高优先级）                    │
│                                                                      │
└─────────────────────────────────────────────────────────────────────┘
```
